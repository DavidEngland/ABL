## Notes for Instructors

- Problems build progressively: neutral profiles → stability functions → Richardson number → grid corrections → ultraspherical theory.
- CBC and Legendre problem sets assume familiarity with generating functions and orthogonal polynomials (graduate level).
- The Jensen's Inequality problem set is suitable as a standalone module for a numerical methods or NWP course.
- Fortran code in [examples/](../examples/) provides working implementations for verification.
