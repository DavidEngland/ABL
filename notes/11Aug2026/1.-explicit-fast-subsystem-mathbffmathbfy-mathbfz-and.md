## 1. Explicit Fast Subsystem \mathbf{F}(\mathbf{y}, \mathbf{z}) and Critical Manifold \mathcal{C}  
To make the critical manifold \mathcal{C} mathematically explicit, consider a 3-variable fast turbulent subsystem \mathbf{y} = (e, \tau, q_\theta)^T, representing Turbulent Kinetic Energy (e = \frac{1}{2}\overline{u_i'u_i'}), momentum flux (\tau = -\overline{u'w'}), and kinematic heat flux (q_\theta = -\overline{w'\theta'}).  
The slow environmental variables are \mathbf{z} = (S, N^2)^T, where S = \Vert{}\partial \mathbf{u}/\partial z\Vert{} is mean vertical shear and N^2 = \frac{g}{\theta_0}\frac{\partial \theta}{\partial z} is buoyancy frequency.  
The fast evolution equations take the form:  
\frac{de}{dt} = \tau S - \frac{g}{\theta_0} q_\theta - \epsilon(e) \frac{d\tau}{dt} = C_1 S e - C_2 \frac{\epsilon(e)}{e} \tau \frac{dq_\theta}{dt} = C_3 \frac{g}{\theta_0} \frac{\partial \theta}{\partial z} e - C_4 \frac{\epsilon(e)}{e} q_\theta  
where \epsilon(e) = C_\mu \frac{e^{3/2}}{l_{\text{mix}}} is the isotropic dissipation rate, and C_1, C_2, C_3, C_4, C_\mu are standard empirical closure constants.  
**Critical Manifold \mathcal{C}**  
In the singular limit \tau_{\text{turb}} \ll \tau_{\text{mean}}, setting \dot{\mathbf{y}} = \mathbf{0} yields the equilibrium relationships:  
```
\tau = \frac{C_1}{C_2} \frac{e^2}{\epsilon(e)} S, \quad q_\theta = \frac{C_3}{C_4} \frac{g}{\theta_0} \frac{e^2}{\epsilon(e)} \frac{\partial \theta}{\partial z}

```
Substituting these flux equilibriums into the TKE budget \tau S - \frac{g}{\theta_0} q_\theta = \epsilon(e) defines the critical manifold surface \mathcal{C}:  
```
\mathcal{C} = \left\{ (e, \tau, q_\theta, S, N^2) \in \mathcal{M} : e = \frac{l_{\text{mix}}^2}{C_\mu^2} S^2 \left( \frac{C_1}{C_2} - \frac{C_3}{C_4} Ri_g \right)^2 \right\}

```
**Fold Set \mathcal{F}**  
The fast Jacobian matrix J_{\mathbf{y}} = \frac{\partial \mathbf{F}}{\partial \mathbf{y}} evaluated along \mathcal{C} becomes singular (\det J_{\mathbf{y}} = 0) at the boundary where TKE production and dissipation can no longer balance. This defines the codimension-1 fold set \mathcal{F}:  
```
\mathcal{F} = \left\{ \mathbf{x} \in \mathcal{C} : Ri_g = Ri_{\text{lim}} \equiv \frac{C_1 C_4}{C_2 C_3}, \; e = 0 \right\}

```
Across \mathcal{F}, the real part of the leading eigenvalue \text{Re}(\lambda_1) of J_{\mathbf{y}} crosses zero, marking the loss of normal hyperbolicity and the onset of turbulence collapse.  
## 2. Concrete Riemannian Metric Tensor G_{ij}(\mathbf{x})  
To make d_{\text{fold}} strictly coordinate- and scale-invariant across heterogeneous physical quantities (velocity squared, rates, flux dimensions), G_{ij}(\mathbf{x}) is defined as a diagonal, variance-normalized metric tensor:  
```
G(\mathbf{x}) = \begin{pmatrix} \sigma_e^{-2} & 0 & 0 & 0 & 0 \\ 0 & \sigma_\tau^{-2} & 0 & 0 & 0 \\ 0 & 0 & \sigma_{q_\theta}^{-2} & 0 & 0 \\ 0 & 0 & 0 & \sigma_S^{-2} & 0 \\ 0 & 0 & 0 & 0 & \sigma_{N^2}^{-2} \end{pmatrix}

```
where \sigma_k^2 represents the domain-wide spatio-temporal variance of field k computed over the boundary-layer volume.  
The distance between a local state \mathbf{x} = (e, \tau, q_\theta, S, N^2)^T and a target fold state \mathbf{y}^* \in \mathcal{F} simplifies to a non-dimensional Mahalanobis distance:  
```
\Vert{}\mathbf{x} - \mathbf{y}^*\Vert{}_G = \sqrt{ \frac{(e - e^*)^2}{\sigma_e^2} + \frac{(\tau - \tau^*)^2}{\sigma_\tau^2} + \frac{(q_\theta - q_\theta^*)^2}{\sigma_{q_\theta}^2} + \frac{(S - S^*)^2}{\sigma_S^2} + \frac{(N^2 - N^{*2})^2}{\sigma_{N^2}^2} }

```
The distance coordinate d_{\text{fold}}(\mathbf{x}) = \inf_{\mathbf{y}^* \in \mathcal{F}} \Vert{}\mathbf{x} - \mathbf{y}^*\Vert{}_G is strictly positive, dimensionless, and invariant under linear re-scaling of unit systems.  
## 3. Mechanistic Form of C(d_{\text{fold}}) and Threshold \delta_0  
The attenuation function C(d_{\text{fold}}) governs how local mixing coefficients K_m, K_h decay as the system approaches the loss of normal hyperbolicity. Rather than an arbitrary choice, C(d_{\text{fold}}) is formulated using hyperbolic continuation:  
```
C(d_{\text{fold}}) = \tanh\left( \frac{d_{\text{fold}}}{\delta_0} \right)

```
**Physical Scaling of \delta_0**  
The transition parameter \delta_0 represents the characteristic geometric width of the boundary layer boundary zone in state space. It is linked directly to the timescale ratio \epsilon = \tau_{\text{fast}} / \tau_{\text{slow}} via singular perturbation theory:  
```
\delta_0 \sim \sqrt{\epsilon} = \sqrt{\frac{l_{\text{mix}} / \sqrt{e_0}}{U_0 / L_x}}

```
where e_0 is mean boundary-layer TKE and U_0 / L_x is the large-scale advective rate.  
* When d_{\text{fold}} \gg \delta_0, \tanh(d_{\text{fold}}/\delta_0) \to 1, restoring unperturbed Monin-Obukhov transport.  
* When d_{\text{fold}} \to 0, C(d_{\text{fold}}) \sim d_{\text{fold}} / \delta_0, providing linear algebraic attenuation that prevents singular gradient runaway without introducing step-function derivative discontinuities into implicit matrix solvers.  
## 4. Bifurcation and Dynamics Validation Suite  
To eliminate circularity and confirm that \mathcal{F} represents a genuine dynamic bifurcation rather than a static fit, two complementary tests are added:  
```
                            Dynamic Validation Suite
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
    1. Critical Slowing Down                      2. Quasi-Static Hysteresis
       Linearized Fast Spectrum                      Reversible vs Irreversible
       Re(λ_1) -> 0^- as d_fold -> 0                 TKE Paths under Ri_g Forcing

```
**1. Critical Slowing Down (Spectral Decay Test)**  
Linearize the fast subsystem \dot{\mathbf{y}} = \mathbf{F}(\mathbf{y}, \mathbf{z}) around the local state for LES grid points at varying distances d_{\text{fold}}:  
```
J_{\mathbf{y}}(\mathbf{x}) = \frac{\partial \mathbf{F}}{\partial \mathbf{y}}\Bigg\vert{}_{\mathbf{x}}

```
Track the maximum real eigenvalue \lambda_1 = \max \text{Re}(\text{eig}(J_{\mathbf{y}})).  
* **Criterion:** As d_{\text{fold}} \to 0, \lambda_1 \to 0^-. The relaxation time \tau_{\text{relax}} = -1 / \lambda_1 diverges to infinity (\tau_{\text{relax}} \to \infty), providing direct evidence of critical slowing down prior to turbulence collapse.  
**2. Hysteresis Loop Characterization (Bistability Test)**  
In a single-column setup, quasi-statically ramp the background surface cooling rate up and down to drive Ri_g across Ri_{\text{lim}} (0 \to 1.5 Ri_{\text{lim}} \to 0).  
* **Criterion:** Plot state trajectories in (Ri_g, e) space. The collapse path (increasing Ri_g) and recovery path (decreasing Ri_g) will form a closed hysteresis loop, confirming that the transition across d_{\text{fold}} = 0 is a first-order (catastrophic) saddle-node bifurcation rather than a smooth second-order transition.  
## 5. Answers to Clarification Questions  
**Question 1: Gegenbauer vs. Chebyshev Parameterization**  
Chebyshev polynomials T_n(\xi) correspond to the special boundary limit \lambda \to 0 of Gegenbauer polynomials C_n^{(\lambda)}(\xi). From d_{\text{eff}} = 2\lambda + 2, \lambda = 0 corresponds to a 2D planar space (d_{\text{eff}} = 2.0), representing the rigid wall limit where vertical transport is completely suppressed (w = 0).  
Parameterizing continuously by \lambda \in [0, 0.5] allows a unified spectral expansion that interpolates smoothly between:  
* Rigid 2D wall constraint (\lambda = 0 \implies d_{\text{eff}} = 2.0, Chebyshev family T_n),  
* Directional momentum transport (\lambda = 0.25 \implies d_{\text{eff}} = 2.5),  
* Isotropic 3D volume-filling heat transport (\lambda = 0.5 \implies d_{\text{eff}} = 3.0, Legendre family P_n).  
**Question 2: Relation Between d_{\text{fold}} and Recovery Threshold \Delta_{\text{crit}}**  
\Delta_{\text{crit}} is a 1D scalar threshold evaluated along a single projected state axis (such as a critical Richardson number gap \Delta Ri = Ri_c - Ri_g).  
d_{\text{fold}} generalizes \Delta_{\text{crit}} into a coordinate-invariant Riemannian metric distance in the full n-dimensional state space \mathcal{M}. \Delta_{\text{crit}} is the 1D projection of d_{\text{fold}} onto the Ri_g coordinate axis. Using d_{\text{fold}} accounts for TKE, shear, and flux states simultaneously rather than relying on a single scalar proxy.  
**Question 3: Noise Robustness and False Bifurcation Triggers**  
Raw high-resolution LES fields contain turbulent fluctuations \mathbf{x}'(t) that can instantaneously drive local point values across d_{\text{fold}} = 0, triggering false bifurcation flags.  
To prevent measurement noise from corrupting the diagnostic:  
1. **Spatiotemporal Filtering:** Prior to evaluating d_{\text{fold}}, fields are passed through a local Gaussian filter \bar{\mathbf{x}} averaged over a spatial volume L_{\text{filter}} \approx 3 l_{\text{mix}} and temporal window T_{\text{filter}} \approx 5 \tau_{\text{fast}}.  
2. **Phase-Space Manifold Projection:** The distance d_{\text{fold}}(\bar{\mathbf{x}}) is evaluated on the filtered slow manifold field \bar{\mathbf{x}}, isolating structural regime transitions from sub-grid turbulent fluctuations.
