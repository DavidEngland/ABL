To understand how higher-order spatial derivatives map between physical height (\(z\)) and non-dimensional similarity space (\(\zeta\)), atmospheric modelers use **partial exponential Bell polynomials**, \(B_{m,n}(\zeta_z, \zeta_{zz}, \dots)\).

At a 1D coordinate fold or "knee" in the stable boundary layer (where vertical flux divergence balances similarity scaling, \(1 - \zeta L' = 0 \implies \mathbf{\zeta_z = 0}\)), these Bell coefficients undergo a structural collapse governed by **even–odd parity, order thresholds, and double factorials (\((2n-1)!!\))**.

### 1. Gentle Reminder: What is the Double Factorial (\((2n-1)!!\))?

Atmospheric science students are accustomed to standard factorials (\(n! = n \cdot (n-1) \cdots 1\)), but **double factorials** (denoted by \(n!!\)) pop up frequently in combinatorics, Gaussian integrals, and higher-order chain rules.

* **Definition:** The double factorial \(n!!\) is the product of all integers from \(n\) down to \(1\) that share the **same parity (even or odd)** as \(n\).
* **Odd Double Factorials:** For an odd integer \(2n-1\):
  \[(2n-1)!! = (2n-1) \cdot (2n-3) \cdot (2n-5) \cdots 5 \cdot 3 \cdot 1\]
* **Examples:**
  * \(1!! = \mathbf{1}\)
  * \(3!! = 3 \cdot 1 = \mathbf{3}\)
  * \(5!! = 5 \cdot 3 \cdot 1 = \mathbf{15}\)
  * \(7!! = 7 \cdot 5 \cdot 3 \cdot 1 = \mathbf{105}\)

#### The Key Factorial Identity

An odd double factorial can be rewritten in terms of standard factorials and powers of \(2\):
\[(2n-1)!! = \frac{(2n)!}{2^n \, n!}\]

#### Combinatorial Intuition: The "Pairing" Rule

In combinatorics, \((2n-1)!!\) counts the **number of ways to partition a set of \(2n\) items into \(n\) non-overlapping pairs (blocks of size 2)**:

* For \(2\) elements (\(n=1\)): There is \(1!! = \mathbf{1}\) way to make \(1\) pair: \(\{A, B\}\).
* For \(4\) elements (\(n=2\)): There are \(3!! = \mathbf{3}\) ways to form \(2\) pairs:
  1. \(\{\{A, B\}, \{C, D\}\}\)
  2. \(\{\{A, C\}, \{B, D\}\}\)
  3. \(\{\{A, D\}, \{B, C\}\}\)

---

### 2. Algebraic Definition of Partial Bell Polynomials (\(B_{m,n}\))

The partial Bell polynomial \(B_{m,n}(x_1, x_2, \dots, x_{m-n+1})\) encodes the number of ways to partition a set of \(m\) elements into \(n\) non-empty subsets (blocks). In similarity coordinate transformations, \(x_j = \zeta^{(j)} = \frac{d^j \zeta}{dz^j}\) (i.e., \(x_1 = \zeta_z\), \(x_2 = \zeta_{zz}\), \(x_3 = \zeta_{zzz}\), etc.):

\[B_{m,n}(x_1, x_2, \dots) = m! \sum \prod_{j=1}^{m-n+1} \frac{x_j^{k_j}}{(j!)^{k_j} \, k_j!}\]

subject to two simultaneous combinatorial constraints:

1. **Total Block Count Constraint (\(n\)):** \(\sum_{j=1} k_j = n\)
2. **Total Element Weight Constraint (\(m\)):** \(\sum_{j=1} j \cdot k_j = m\)

---

### 3. The Collapse at a Coordinate Fold (\(\zeta_z = x_1 = 0\))

When the first vertical derivative of the similarity coordinate vanishes (\(\mathbf{\zeta_z = x_1 = 0}\)), any partition term containing \(x_1\) (\(k_1 > 0\)) is multiplied by \(0^{k_1} = 0\) and vanishes.

#### Rule 1: The "No Singleton Block" Constraint (\(k_1 = 0\))

For a term to survive at \(\zeta_z = 0\), it must have \(k_1 = 0\). This means **no subset in the partition can have size 1** (\(j \ge 2\) for all blocks).

#### Rule 2: Strict Order Threshold (\(m < 2n \implies B_{m,n} = 0\))

Since every surviving block has size \(j \ge 2\):
\[m = \sum_{j=2} j \cdot k_j \ge 2 \sum_{j=2} k_j = 2n \implies m \ge 2n\]
As a result, **all entries above the sub-diagonal where \(m < 2n\) collapse identically to zero when \(\zeta_z = 0\)**.

#### Rule 3: Double-Factorial Sub-Diagonal Survival (\(m = 2n\))

When the row index is exactly twice the column index (\(m = 2n\)), the inequality \(m = \sum j \cdot k_j \ge 2n\) becomes an exact equality. The **only** valid partition is \(k_2 = n\) (i.e., all \(n\) blocks have size \(j=2\), and \(k_3 = k_4 = \dots = 0\)).

Substituting \(k_2 = n\) into the Bell polynomial definition yields:

\[B_{2n, n}\Big|_{\zeta_z = 0} = (2n)! \, \frac{\left(\frac{x_2}{2!}\right)^n}{n!} = \frac{(2n)!}{2^n \, n!} \, x_2^n = \mathbf{(2n - 1)!! \; \zeta_{zz}^n}\]

This is the exact mathematical origin of the double factorial in partial Bell transformation matrices!

### 4. Structure of the \(4 \times 4\) Partial Bell Matrix at the Fold

Evaluating the general \(4 \times 4\) transformation matrix \(\mathbf{B}\) at \(\zeta_z = 0\):

\[\mathbf{B} = \begin{bmatrix}

\zeta_{zz} & \zeta_z^2 & 0 & 0 \
\zeta_{zzz} & 3\zeta_z\zeta_{zz} & \zeta_z^3 & 0 \

\xrightarrow{\zeta_z = 0}
\mathbf{B}\Big|_{\zeta_z = 0} = \begin{bmatrix}

\zeta_{zz} & 0 & 0 & 0 \

Notice how the entry at row \(m=4\), column \(n=2\) satisfies \(m = 2n\):
\[B_{4,2}\Big|_{\zeta_z = 0} = (2(2) - 1)!! \; \zeta_{zz}^2 = 3!! \, \zeta_{zz}^2 = \mathbf{3\zeta_{zz}^2}\]

# High-Order Hyperdiffusion and Richardson Number Dynamics in Atmospheric Boundary-Layer Modeling

## 1. Theoretical Foundations: Gradient Richardson Number Dynamics and Monin–Obukhov Linkage

Modern Numerical Weather Prediction (NWP) models and atmospheric boundary-layer parameterizations require computationally efficient methods to evaluate turbulent exchange and thermal stratification. Historically, non-dimensional Monin–Obukhov Similarity Theory (MOST) relied on iterative sub-loops to determine the dimensionless stability parameter \(\zeta = z/L\) (where \(z\) is physical height and \(L\) is the Obukhov length scale). In high-performance computing environments—specifically vector processing units and Graphics Processing Units (GPUs)—iterative loops induce severe performance bottlenecks due to conditional branching and warp divergence. Eliminating sub-iterations by mapping MOST functions directly into physical Gradient Richardson Number (Ri) space provides a direct, non-iterative, closed-form mapping. This mathematical bridge preserves exact algebraic fidelity with MOST while enabling unified, single-pass forward evaluations across all stability regimes.

1.1 Core Formulations & Exact $S_m(Ri) / S_h(Ri)$ Mapping

The parameterization of first-order turbulent exchange coefficients for momentum \(K_m\) and heat or scalars \(K_h\) links the Monin–Obukhov similarity framework to local gradient formulations:

* Monin–Obukhov Formulation (\(\zeta = z/L\)): \(K_m = \frac{l_m u_*}{\phi_m(\zeta)}, \qquad K_h = \frac{l_m u_*}{\phi_h(\zeta)}\)
* Gradient Richardson Number Formulation (Ri): \(K_m = S_m(Ri) \, l_m^2 s, \qquad K_h = S_h(Ri) \, l_m^2 s\)

where \(l_m = \kappa (z - d)\) represents the surface-layer mixing length, \(u_*\) is the friction velocity, \(s = |\partial \mathbf{V} / \partial z|\) is the magnitude of vertical wind shear, and \(\phi_m(\zeta), \phi_h(\zeta)\) are the non-dimensional MOST gradient functions. The dimensionless exchange stability functions \(S_m(Ri)\) and \(S_h(Ri)\) encapsulate the damping effects of thermal stratification on mechanical turbulence.

Equating friction velocity \(u_*= S_m^{1/2} l_m s\) and scalar scale \(\theta_* = (S_h / S_m^{1/2}) l_m (\partial \theta_v / \partial z)\) within the analytical definition of the Obukhov length \(L = u_*^2 / (\kappa B \theta_*)\)—where \(B = g / \theta_{v,\mathrm{ref}}\) is the buoyancy parameter—yields the exact dual transformation identity:

\[\zeta(Ri) = Ri \frac{S_h(Ri)}{S_m^{3/2}(Ri)}\]

The exponent of 3/2 on \(S_m(Ri)\) in the denominator is a strict physical and mathematical requirement. When the turbulent Prandtl number \(\mathrm{Pr}_t = K_m / K_h = S_m(Ri) / S_h(Ri) = \phi_h(\zeta) / \phi_m(\zeta)\) deviates from unity (\(\mathrm{Pr}_t \neq 1\)), any exponent other than 3/2 violates dimensional consistency and creates algebraic discrepancies between friction velocity and local gradient definitions.

1.2 Regime-Specific Analytical Inversions

Stable Boundary Layer (SBL, Ri > 0)

For linear non-dimensional MOST gradients under stable stratification, \(\phi_m(\zeta) = 1 + \beta_m \zeta\) and \(\phi_h(\zeta) = \alpha_\theta + \beta_h \zeta\) (where \(\alpha_\theta = \mathrm{Pr}_t(0)\) is the neutral turbulent Prandtl number), inverting the stability relations yields an exact quadratic equation for \(\zeta(Ri)\):

\[\zeta(Ri) = \frac{\alpha_\theta - 2 Ri \beta_m - \sqrt{\alpha_\theta^2 + 4(\beta_h - \alpha_\theta \beta_m)Ri}}{2(Ri \beta_m^2 - \beta_h)}, \qquad 0 \le Ri < Ri_c = \frac{\beta_h}{\beta_m^2}\]

A crucial mathematical constraint in this quadratic solution is the selection of the negative root before the radical. Selecting the positive root yields:

\[\lim_{Ri \to 0^+} \zeta_{+}(Ri) = \frac{2\alpha_\theta}{0} \to \frac{\alpha_\theta}{-\beta_h} \neq 0\]

Evaluating the positive root at \(Ri = 0\) yields a non-zero constant, creating an unphysical step discontinuity at neutral stability and violating the foundational physical boundary condition \(\zeta(0) = 0\). Selecting the negative root strictly enforces \(\zeta(0) = 0\) through L'Hôpital's rule:

\[\lim_{Ri \to 0^+} \zeta_{-}(Ri) = \lim_{Ri \to 0^+} \frac{\frac{d}{dRi}\left[\alpha_\theta - 2 Ri \beta_m - \sqrt{\alpha_\theta^2 + 4(\beta_h - \alpha_\theta \beta_m)Ri}\right]}{\frac{d}{dRi}\left[2(Ri \beta_m^2 - \beta_h)\right]} = \frac{-2\beta_m - \frac{2(\beta_h - \alpha_\theta \beta_m)}{\alpha_\theta}}{-2\beta_h} = \frac{\beta_h/\alpha_\theta}{\beta_h} = \frac{1}{\alpha_\theta}\]

When equal diffusivities at neutrality are assumed (\(\alpha_\theta = 1\)) alongside matching empirical coefficients (\(\beta_m = \beta_h = \beta\)), the critical Richardson number becomes \(Ri_c = 1/\beta\). In this equal-diffusivity limit (\(Pr_0 = 1\)), the exchange stability functions collapse into a smooth quadratic expression:

\[
S_m(Ri) = S_h(Ri) = \begin{cases} \left(1 - \frac{Ri}{Ri_c}\right)^2, & 0 \le Ri < Ri_c \\ 0, & Ri \ge Ri_c \end{cases}
\]

This smooth quadratic form guarantees continuous first derivatives across the extinction threshold (\(Ri \to Ri_c^-\)). Because \(\partial S_m / \partial Ri \to 0\) as \(Ri\) approaches \(Ri_c\), the formulation preserves \(C^1\) derivative continuity, preventing artificial limit-cycle oscillations, grid-scale numerical noise, and Jacobian singularities during implicit time integration.

While classical SBL parameterizations impose a hard critical cutoff \(S_m = 0\) for \(Ri \ge Ri_c\), modern Very Stable Boundary Layer (VSBL) research (e.g., Gryanik et al., 2020; Energy and Flux Budget [EFB] theory, Casasanta et al., 2025) replaces zero-extinction limits with non-zero asymptotic tails (\(\phi_m, \phi_h \sim \zeta^1\) as \(\zeta \to \infty\)). These non-zero tails account for wave-turbulence transport and intermittent mixing under strong thermal stratification, preventing catastrophic nocturnal runaway surface cooling and physical decoupling in land-surface models.

Unstable Boundary Layer (UBL, Ri < 0)

Under unstable conditions, adopting standard Businger–Dyer empirical exponents (\(\alpha_m = -1/4, \alpha_h = -1/2\)) maps the relation between \(\zeta\) and \(Ri\) into a Master Cubic polynomial in \(x \equiv \zeta\):

\(b_m \zeta^3 - \zeta^2 - b_h \left(\frac{Ri}{\alpha_\theta}\right)^2 \zeta + \left(\frac{Ri}{\alpha_\theta}\right)^2 = 0\)

When the momentum and scalar empirical exponents match identically (\(b_m = b_h = B_u \approx 16\) and \(\alpha_\theta = 1.0\)), the transformation identity experiences an exact algebraic collapse:

\(\phi_m(\zeta) = (1 - B_u \zeta)^{-1/4} \implies S_m(Ri) = (1 - B_u \zeta)^{1/2} \phi_h(\zeta) = (1 - B_u \zeta)^{-1/2} \implies S_h(Ri) = (1 - B_u \zeta)^{3/4} = S_m^{3/2}(Ri)\)

Substituting S_m(Ri) and S_h(Ri) into the dual transformation identity yields:

\(\zeta = Ri \frac{S_h(Ri)}{S_m^{3/2}(Ri)} = Ri \frac{(1 - B_u \zeta)^{3/4}}{\left[(1 - B_u \zeta)^{1/2}\right]^{3/2}} = Ri \frac{(1 - B_u \zeta)^{3/4}}{(1 - B_u \zeta)^{3/4}} \equiv Ri\)

Under this "Dyer collapse," \(\zeta\) equals \(Ri\) identically across the entire unstable domain, eliminating mapping error and cubic solvers entirely.

For non-equal exponents (\(b_m \neq b_h\)), floating-point operations near neutral stability (\(|Ri| \ll 1\)) can suffer from numerical loss of precision if evaluated via trigonometric cubic roots. Numerical stability near \(Ri \to 0^-\) is preserved by applying a series reversion via Lagrange inversion polynomials:

\(\zeta(Ri) \approx \frac{Ri}{\alpha_\theta} \left[ 1 + \lambda_1 \left(\frac{Ri}{\alpha_\theta}\right) + \lambda_2 \left(\frac{Ri}{\alpha_\theta}\right)^2 + \mathcal{O}(Ri^3) \right]\)

where \(\lambda_1 = b_m - b_h\) and \(\lambda_2 = (b_m - b_h)^2 + \frac{1}{2}b_m b_h\).

Numerical Regularization & GPU Alignment

To maximize computational throughput on hardware architectures sensitive to thread divergence, conditional logic (if/else branching across Ri = 0) must be removed. Zero-Offset Hyperbolic Regularization (Z0HR) replaces piecewise logic by decomposing Ri into C^\infty-smooth positive (stable) and negative (unstable) projections using an \epsilon-regularized absolute value:

\(|Ri|_\epsilon = \sqrt{Ri^2 + \epsilon^2}, \qquad Ri_+ = \frac{1}{2}\left(Ri + |Ri|_\epsilon - \epsilon\right), \qquad Ri_- = \frac{1}{2}\left(Ri - |Ri|_\epsilon + \epsilon\right)\)

Smooth weight functions \(w_{\text{stable}} = \frac{1}{2}\left(1 + \frac{Ri}{|Ri|_\epsilon}\right)\) and continuous hyperbolic tangent embeddings \(\left(S_m(Ri) = \frac{1}{2}[1 - \tanh(\sigma Ri)] S_{m,\text{uns}} + \frac{1}{2}[1 + \tanh(\sigma Ri)] S_{m,\text{sta}}\right)\) allow unified, branch-free execution. Removing conditional branching eliminates GPU warp divergence and CPU instruction pipeline stalls, accelerating execution across mass-parallel grid cells.

Having established the non-iterative mapping of scalar stability functions into physical coordinate space, the analysis turns to mapping higher-order vertical spatial derivatives of these profiles.

## 1. Higher-Order Spatial Derivatives and Partial Bell Matrix Mappings

Evaluating higher-order vertical spatial derivatives of the Gradient Richardson Number \(Ri_z, Ri_{zz}, Ri_{zzz}, Ri_{zzzz}\) is essential for high-order spatial discretizations, sub-grid scale diffusion models, and turbulence stability analyses. When Monin–Obukhov stability profiles \(R(\zeta)\) are transformed into physical vertical coordinates \(z\), the derivative chains generate non-linear couplings between intrinsic stability curvature and geometric coordinate variations. A mathematically rigorous mapping framework is required to transform non-dimensional derivative vectors into physical spatial derivative vectors without truncation errors.

### 1.1 Faà di Bruno’s Chain Rule and the Partial Bell Matrix \(\mathbf{B}\)

Differentiating a composite function \(Ri(z) = R(\zeta(z))\) m times with respect to physical height z is governed by Faà di Bruno’s higher-order chain rule formula:

\(\frac{d^m}{dz^m} R(\zeta(z)) = \sum_{n=1}^{m} R^{(n)}(\zeta) \cdot B_{m,n}\left(\zeta_z, \zeta_{zz}, \dots, \zeta_{(m-n+1)z}\right)\)

where \(B_{m,n}\) represents the partial exponential Bell polynomial (Bell polynomial of the second kind), which combinatorially counts the partitions of a set of m elements into n non-empty subsets.

To maintain unambiguous notation between derivative operators and local coefficient values, let \(g_j \equiv \frac{d^j \zeta}{d z^j}\) denote spatial coordinate derivatives (where \(g_1 = \zeta_z, g_2 = \zeta_{zz}\), etc.). Collecting derivative components up to fourth order constructs the lower-triangular \(4 \times 4\) Partial Bell Transformation Matrix system \(\mathbf{Ri}_z = \mathbf{B} \mathbf{R}_\zeta\):
\[
\begin{bmatrix} Ri_z \\ Ri_{zz} \\ Ri_{zzz} \\ Ri_{zzzz} \end{bmatrix} = \begin{bmatrix} \zeta_z & 0 & 0 & 0 \\ \zeta_{zz} & \zeta_z^2 & 0 & 0 \\ \zeta_{zzz} & 3\zeta_z\zeta_{zz} & \zeta_z^3 & 0 \\ \zeta_{zzzz} & 4\zeta_z\zeta_{zzz} + 3\zeta_{zz}^2 & 6\zeta_z^2\zeta_{zz} & \zeta_z^4 \end{bmatrix} \begin{bmatrix} R'(\zeta) \\ R''(\zeta) \\ R'''(\zeta) \\ R^{(4)}(\zeta) \end{bmatrix} \]

The individual matrix entries \(B_{m,n}\) can be assembled using two equivalent recurrence relations:

1. Combinatorial Summation Recurrence (Faà di Bruno Identity): \(B_{m+1, n} = \sum_{j=n-1}^{m} \binom{m}{j} g_{m+1-j} B_{j, n-1} \quad \text{with } B_{0,0} = 1\)
2. Differential Recurrence (Subroutine-Friendly Iteration): \(B_{m+1, n} = \zeta_z B_{m, n-1} + \frac{d}{dz} B_{m, n}\) with boundary conditions \(B_{m,0} = 0\) for \(m \ge 1\) and \(B_{m,k} = 0\) for \(k > m\).

### 1.2 Inverse Bell Mapping \(\mathbf{B}^{-1}\) and Observational Parameter Calibration

Because \(\mathbf{B}\) is lower-triangular with diagonal entries \(B_{k,k} = \zeta_z^k\), its determinant is \(\det(\mathbf{B}) = \zeta_z^{10}\). When \(\zeta_z \neq 0\), inverting this matrix maps physical spatial derivatives back into non-dimensional similarity derivatives \(\mathbf{R}_\zeta = \mathbf{B}^{-1} \mathbf{Ri}_z\):
\[
\begin{bmatrix} R'(\zeta) \\ R''(\zeta) \\ R'''(\zeta) \\ R^{(4)}(\zeta) \end{bmatrix} = \begin{bmatrix} \frac{1}{\zeta_z} & 0 & 0 & 0 \\ -\frac{\zeta_{zz}}{\zeta_z^3} & \frac{1}{\zeta_z^2} & 0 & 0 \\ \frac{3\zeta_{zz}^2 - \zeta_z \zeta_{zzz}}{\zeta_z^5} & -\frac{3\zeta_{zz}}{\zeta_z^4} & \frac{1}{\zeta_z^3} & 0 \\ \frac{10\zeta_z \zeta_{zz} \zeta_{zzz} - 15\zeta_{zz}^3 - \zeta_z^2 \zeta_{zzzz}}{\zeta_z^7} & \frac{10\zeta_{zz}^2 - 4\zeta_z \zeta_{zzz}}{\zeta_z^6} & -\frac{6\zeta_{zz}}{\zeta_z^5} & \frac{1}{\zeta_z^4} \end{bmatrix} \begin{bmatrix} Ri_z \\ Ri_{zz} \\ Ri_{zzz} \\ Ri_{zzzz} \end{bmatrix}
\]

This analytical inverse provides a diagnostic tool for observational dynamicists. Processing high-resolution field tower or Large-Eddy Simulation (LES) profile data through \(\mathbf{B}^{-1}\) extracts non-dimensional similarity derivatives (\(R', R'', R''', R^{(4)}\)) a priori directly from measured physical profiles without prescribing functional forms. Near neutral stability (\(\zeta \to 0\)), empirical expansion slopes (\(\beta_m, \beta_h\)) and the neutral Prandtl number \(\alpha_\theta = Pr_t(0)\) are diagnosed via:
\[
\alpha_\theta = \left. \frac{Ri_z}{\zeta_z} \right|_{\zeta \to 0}, \qquad 2(\beta_h - 2\alpha_\theta \beta_m) = \left. \frac{Ri_{zz} - \frac{\zeta_{zz}}{\zeta_z} Ri_z}{\zeta_z^2} \right|_{\zeta \to 0}
\]

Crucially, at or near a coordinate fold knee (\(\zeta_z \to 0\)), the transformation matrix becomes rank-deficient (\(\det(\mathbf{B}) = 0\)). Consequently, observational parameter calibration routines cannot directly invert field profile data via \(\mathbf{B}^{-1}\) at a knee. Near coordinate folds, local chart transitions, singular-value decomposition (SVD), or Tikhonov regularization (\(D_\lambda^{(2)} = (A^T A + \lambda R)^{-1} A^T\)) must be applied to prevent division-by-zero singularities.

### 1.3 Asymptotic Limits and NWP Solver Physics

Near-Neutral Limit \(\zeta \to 0\)

Evaluating non-dimensional profile curvature \(R''(0)\) near neutral stability reveals a key mathematical distinction between single-coefficient and dual-coefficient MOST closures:

* Single-Coefficient Closure \(\left(R(\zeta) = \frac{\zeta}{1 + \beta \zeta}, \beta = 5.0\right): R''(0) = -2\beta = -10.0\)
* Dual-Coefficient Closure \(\left(R(\zeta) = \frac{\zeta(\alpha_\theta + \beta_h \zeta)}{(1 + \beta_m \zeta)^2}, \alpha_\theta = 1.0, \beta_m = 6.0, \beta_h = 5.0\right): R''(0) = 2(\beta_h - 2\alpha_\theta \beta_m) = 2(5.0 - 12.0) = -14.0\)

The dual-coefficient model produces a ~40% steeper initial curvature spike near neutrality (\(R''(0) = -14.0\) vs. -10.0). On discrete C-grid vertical meshes, this steeper initial curvature accelerates spatial gradient variations near the surface:

\[\lim_{\zeta \to 0} Ri_{zzzz} = \zeta_{zzzz} + R''(0) (4\zeta_z \zeta_{zzz} + 3\zeta_{zz}^2) + R'''(0) (6\zeta_z^2 \zeta_{zz}) + R^{(4)}(0) \zeta_z^4\]

Because pre-factor damping terms approach unity near neutrality, grid-driven spatial derivatives excite numerical ringing on discrete vertical grids. This provides the mathematical justification for mandatory softening noise floor parameters (\epsilon_c Ri_c > 0) in surface-layer modules to bound spatial derivative amplification near neutrality without corrupting physical turbulent fluxes.

High-Stability Limit \(\zeta \gg 1\)

Under strongly stable conditions \(\zeta \to \infty\), higher-order non-dimensional derivatives exhibit power-law decay:

\(R^{(n)}(\zeta) \approx (-1)^n n! \, \frac{\alpha_\theta \beta_m - 2\beta_h}{\beta_m^3} \zeta^{-(n+1)} \sim \mathcal{O}\left(\zeta^{-(n+1)}\right)\)

Assuming a locally constant Obukhov length L, physical vertical derivatives scale as:

\(\frac{d^n Ri}{dz^n} \propto \frac{L}{z^{n+1}}\)

For fourth-order derivatives, \(Ri_{zzzz} \propto z^{-5}\). This rapid decay proves that standard MOST closures naturally suppress numerical noise aloft. Consequently, if persistent grid-scale oscillations are observed aloft in strongly stable layers during model execution, they indicate non-MOST physical processes (such as gravity wave breaking or shear instability) or spurious wave reflection at domain boundaries, rather than inherent MOST model instability.

Having mapped the continuous spatial derivatives of stability profiles, attention turns to the discrete operators designed to damp computational noise across these spatial scales.

### Mechanics of Biharmonic and Higher-Order Hyperdiffusion Operators

High-order hyperdiffusion operators are numerical dissipation mechanisms, not replacements for physically based turbulent transport closures. Their operational role in atmospheric models is to attenuate high-wavenumber grid noise near the spatial truncation limit (2\Delta z) while leaving larger, physically resolved boundary-layer structures unattenuated.

3.1 Scale-Selective Dissipation Mechanics

To prevent physical growth from being misinterpreted as damping, numerical filters must adhere to an unambiguous dissipative sign convention. For a model field \(q(\mathbf{x}, t)\), the order-2p spatial filtering tendency is defined as:

\[\left.\frac{\partial q}{\partial t}\right|_{\mathrm{filter}} = -\nu_{2p}(-\Delta)^p q = (-1)^{p+1}\nu_{2p}\Delta^p q\]

where \(\Delta = \nabla^2\) is the physical Laplacian operator, \(p \ge 1\) is an integer defining spatial derivative order \(2p\), and \(\nu_{2p} \ge 0\) is the constant hyperdiffusion coefficient.

The table below summarizes the operational properties across spatial orders:

Spatial Derivative Order (\(2p\)) Common Operator Name Dissipative Tendency Expression Fourier Decay Rate (\(\sigma_{2p}(k)\))
2 Laplacian Diffusion \(+\nu_2 \Delta q\) \(\nu_2 k^2\)
4 Biharmonic Hyperdiffusion \(-\nu_4 \Delta^2 q\) \(\nu_4 k^4\)
6 Triharmonic Hyperdiffusion \(+\nu_6 \Delta^3 q\) \(\nu_6 k^6\)
8 Eighth-Order Hyperdiffusion \(-\nu_8 \Delta^4 q\) \(\nu_8 k^8\)
2p General Even-Order \((-1)^{p+1}\nu_{2p} \Delta^p q\) \(\nu_{2p} k^{2p}\)

Applying the continuum operator to a spatial Fourier mode \(\widehat{q} e^{i k z}\) yields the amplitude decay equation \(\frac{d\widehat{q}}{dt} = -\nu_{2p} k^{2p} \widehat{q}\). Calibrating the hyperdiffusion coefficient to achieve a target e-folding damping time \(\tau_g\) at reference grid-scale wavenumber \(k_g = \pi / h\) gives:

\(\nu_{2p} = \frac{1}{\tau_g k_g^{2p}} \implies \sigma_{2p}(k) = \frac{1}{\tau_g} \left(\frac{k}{k_g}\right)^{2p}\)

Evaluating decay rates at half the reference wavenumber \((k / k_g = 0.5\), corresponding to \(4\Delta z\) waves) demonstrates scale selectivity:

\(\frac{\sigma_2(0.5k_g)}{\sigma_2(k_g)} = \frac{1}{4}, \qquad \frac{\sigma_4(0.5k_g)}{\sigma_4(k_g)} = \frac{1}{16}, \qquad \frac{\sigma_6(0.5k_g)}{\sigma_6(k_g)} = \frac{1}{64}, \qquad \frac{\sigma_8(0.5k_g)}{\sigma_8(k_g)} = \frac{1}{256}\)

Increasing spatial derivative order sharpens scale selectivity, damping \(2\Delta z\) noise while preserving longer resolved waves.

On a discrete uniform grid using a centered 3-point Laplacian, continuum wavenumber calibration \(k^2\) is inaccurate. Calibration must use the discrete Laplacian eigenvalue \(\mu(k) = \frac{4}{h^2} \sin^2\left(\frac{kh}{2}\right)\):

\(\sigma_{2p}(k) = \nu_{2p} [\mu(k)]^p\)

At the shortest grid wavelength \(2h\) (\(kh = \pi\)), \(\mu_g = 4/h^2\). The discrete matched coefficient is \(\nu_{2p} = 1 / (\tau_g \mu_g^p) = h^{2p} / (4^p \tau_g)\). This discrete calibration differs substantially from using \(k_g = \pi / h\) in the continuum formula (\(\nu_{2p} = h^{2p} / (\pi^{2p} \tau_g)\)). For fourth-order biharmonic hyperdiffusion (\(p=2\)), comparing the continuum coefficient to the discrete eigenvalue calibration yields:

\(\frac{\nu_{4,\mathrm{continuum}}}{\nu_{4,\mathrm{discrete}}} = \frac{h^4 / (\pi^4 \tau_g)}{h^4 / (16 \tau_g)} = \frac{\pi^4}{16} \approx \frac{97.41}{16} \approx 6.09\)

A naive application of the continuum calibration formula over-damps \(2\Delta z\) grid modes by a factor of \(\frac{\pi^4}{16} \approx 6.09\), severely eroding resolved mesoscale gradients and physically valid inversion structures.

3.2 Global Norm Dissipation vs. Local Pointwise Dynamics

For periodic domains or boundary conditions where \(A = -\Delta\) is a non-negative self-adjoint operator, define the domain-integrated quadratic norm \(E_q = \frac{1}{2} \langle q, q \rangle\). The domain-integrated filter tendency satisfies:

\(\left.\frac{d E_q}{d t}\right|_{\mathrm{filter}} = -\nu_{2p} \langle q, A^p q \rangle = -\nu_{2p} \int_{\Omega} \left(\frac{\partial^p q}{\partial z^p}\right)^2 dz \le 0\)

This proves that hyperdiffusion globally dissipates the quadratic norm (kinetic energy for velocity components, variance for scalar fields). However, global norm dissipation does not guarantee local pointwise monotonicity. Pointwise tendencies \(\left.\frac{\partial q}{\partial t}\right|_{\mathrm{filter}}\) can be locally positive near sharp spatial gradients while domain-integrated energy decreases.

Unlike second-order diffusion (\(p=1\)), fourth- and higher-order filters (\(p \ge 2\)) lack a pointwise maximum principle. Consequently, biharmonic filters near sharp temperature inversions or Low-Level Jets generate localized unphysical overshoots (Gibbs ringing). In numerical models, these unphysical oscillations can drive positive-definite scalar fields—such as water vapor mixing ratio \(q_v\), cloud water \(q_c\), or Turbulent Kinetic Energy \(e\)—negative. Preserving physical non-negativity requires pairing high-order filters with non-linear flux limiters (such as TVD or Zalesak multidimensional limiters) evaluated specifically for mass conservation.

Physical turbulent transport \(\left.\frac{\partial q}{\partial t}\right|_{\mathrm{turb}} = \frac{\partial}{\partial z}\left(K_q \frac{\partial q}{\partial z}\right)\) must be kept strictly distinct from numerical filtering \(-\nu_4 \nabla^4 q\). Direct filtering of diagnostic fields such as Ri is non-equivalent to filtering prognostic state variables \((u, v, \theta_v)\) and recomputing diagnostics. In dynamical models, hyperdiffusion must be applied directly to prognostic state variables, with diagnostic fields recomputed from the filtered state.

Having established operator dissipation mechanics, the analysis connects these discrete spatial filters to vertical profile kinematics and coordinate singularities.

## 1. Kinematics of Boundary-Layer Profiling: GSPT, Singularities, and Inflection Geometry

Generalized Similarity Profile Theory (GSPT) projects continuous state-space dynamics onto a 1D non-dimensional similarity coordinate \(\zeta(z) = z / L(z)\). In real boundary layers with height-varying turbulent fluxes, coordinate stretching introduces kinematic features that must be distinguished from physical fluid dynamics.

4.1 Kinematic Features: The Jet "Nose" vs. The Coordinate "Knee"

Stable boundary layers under nocturnal cooling frequently generate Low-Level Jets (LLJs). Modern modeling requires distinguishing two distinct profile features:

* The LLJ "Nose" (Kinematic Momentum Maximum): A physical fluid-dynamical feature located at jet peak height \(z_{\text{LLJ}}\), where mean vertical wind vector shear vanishes \(\frac{dU}{dz} = 0\). Because vertical shear appears squared in the denominator of the Richardson number \(\mathrm{Ri} = \frac{g}{\theta_0} \frac{\partial \theta_v / \partial z}{(\partial U / \partial z)^2 + (\partial V / \partial z)^2}\), vanishing shear causes raw point-gradient Ri values to diverge toward \(+\infty\).
* The Coordinate "Knee" (Coordinate Fold Singularity): A mathematical projection artifact. Differentiating \(\zeta(z) = z/L(z)\) with respect to physical height \(z\) yields \(g_1 = \zeta_z = \frac{d\zeta}{dz} = \frac{1 - \zeta L'}{L}\), where \(L' = dL/dz\) represents vertical flux divergence. Where local flux divergence balances similarity scaling (\(\zeta L' = 1\)), the coordinate derivative vanishes (\(\zeta_z = 0\)), creating a 1D coordinate fold singularity (loss of local coordinate invertibility).

4.2 GSPT Three-Way Curvature Decomposition

Applying total differentiation to Ri(\zeta(z)) decomposes physical vertical profile curvature into three components:

\[\frac{d^2 \mathrm{Ri}}{dz^2} = \underbrace{\mathrm{Ri}_{\zeta\zeta} \zeta_z^2}_{\text{Intrinsic Stability Geometry}} + \underbrace{\mathrm{Ri}_\zeta \zeta_{zz}}_{\text{Coordinate/Flux Geometry}} + \underbrace{\mathcal{E}_{\Delta z}}_{\text{Estimation Error}}\]

At a coordinate fold singularity (\(\zeta_z = 0, \zeta_{zz} \neq 0\)), the Partial Bell Transformation Matrix \(\mathbf{B}\) undergoes structural collapse:

\[\mathbf{B}\Big|_{\zeta_z = 0} = \begin{bmatrix} 0 & 0 & 0 & 0 \\ \zeta_{zz} & 0 & 0 & 0 \\ \zeta_{zzz} & 0 & 0 & 0 \\ \zeta_{zzzz} & 3\zeta_{zz}^2 & 0 & 0 \end{bmatrix} \implies \begin{bmatrix} \mathrm{Ri}_z \\ \mathrm{Ri}_{zz} \\ \mathrm{Ri}_{zzz} \\ \mathrm{Ri}_{zzzz} \end{bmatrix}_{\zeta_z = 0} = \begin{bmatrix} 0 \\ R'(\zeta) \zeta_{zz} \\ R'(\zeta) \zeta_{zzz} \\ R'(\zeta) \zeta_{zzzz} + 3 R''(\zeta) \zeta_{zz}^2 \end{bmatrix}\]

At the fold, physical gradients flatten (\(\mathrm{Ri}_z = 0\)) and intrinsic thermodynamic stability curvature vanishes (\(\mathrm{Ri}_{\zeta\zeta} \zeta_z^2 = 0\)). Physical profile bending reduces purely to coordinate geometry (\(\mathrm{Ri}_{zz} = R'(\zeta) \zeta_{zz}\)). Tower evaluations (e.g., CASES-99, GABLS3) confirm that over 99% of observed profile bending at a coordinate knee is driven by coordinate compression (\(\zeta_{zz}\)) rather than intrinsic thermodynamic stability breakdown.

At fourth order, biharmonic hyperdiffusion reactivates at the fold via the non-zero Bell polynomial entry \(B_{4,2} = 3\zeta_{zz}^2\). The resulting fourth derivative contains the active term \(3 R''(\zeta) \zeta_{zz}^2\), allowing biharmonic filters (\(-\nu_4 \nabla^4 \mathrm{Ri}\)) to smooth grid noise at the fold without misinterpreting coordinate stretching as physical turbulence generation.

Defining \(g_j \equiv \frac{d^j \zeta}{dz^j}\), the table below lists Bell polynomial entries at a coordinate fold (\(\zeta_z = 0\)) up to tenth order, showing surviving non-dimensional derivatives \(R^{(p)}\):

| Physical Derivative Order (2p) | Highest Surviving Similarity Derivative | Bell Polynomial Entry \(B_{2p, p}\big|_{\zeta_z=0}\) | Exact Combinatorial Entry |
| :--- | :--- | :--- | :--- |
 2 | \(R'(\zeta)\) | \(g_2\) | \(1 \cdot g_2\) |
| 4 | \(R''(\zeta)\) | \(3 g_2^2\) | \(3 \cdot g_2^2 = (3!!) g_2^2\) |
| 6 | \(R'''(\zeta)\) | \(15 g_2^3\) | \(15 \cdot g_2^3 = (5!!) g_2^3\) |
| 8 | \(R^{(4)}(\zeta)\) | \(105 g_2^4\) | \(105 \cdot g_2^4 = (7!!) g_2^4\) |
| 10 | \(R^{(5)}(\zeta)\) | \(945 g_2^5\) | \(945 \cdot g_2^5 = (9!!) g_2^5\) |

The surviving coefficient for derivative order 2p at a fold follows the double-factorial formula (2p-1)!! g_2^p. Computational modelers must interpret these combinatorial entries as descriptions of mathematical function composition geometry across coordinate transforms. They do not represent a physical fivefold increase in numerical filter strength or localized physical turbulence generation.

4.3 The Triple-Point Invariant-Convergence Hypothesis

To prevent modelers from mistaking coordinate fold artifacts or grid truncation errors for true physical turbulence collapse, GSPT establishes the Triple-Point Invariant-Convergence Hypothesis. Physical turbulence extinction is verified by tracking the spatial convergence of three independent physical heights as vertical grid spacing vanishes \(\Delta z \to 0\):

1. Diffusivity Extinction Height (\(z_K\)): The level where exchange diffusivity reaches its background floor (\(K_m \to K_{\min}\)).
2. TKE Floor Height (\(z_e\)): The level where Turbulent Kinetic Energy reaches its minimum floor (\(e \to e_{\min}\)).
3. Shear Stress / TKE Gradient Extremum Height (\(z_{e_z}\)): The level where vertical stress divergence or TKE gradients reach a localized peak (\(\frac{\partial^2}{\partial z^2}(u_*^2) \to \text{max}\)).

If the spatial spread \(\Delta z_{\text{TP}} = \max|z_i - z_j|\) collapses to zero as \(\Delta z \to 0\), the feature represents a physical turbulence transition rather than a grid artifact.

Having established continuous profile kinematics, the next section addresses discrete operator engineering on non-uniform numerical grids.

1. Discretization, Boundary Layer Coupling, and Advanced Time-Stepping

Implementing fourth-order hyperdiffusion on operational NWP vertical grids presents numerical challenges. Vertical grids are non-uniform and stretched, with fine spacing near the surface (\(\Delta z \sim 10\text{ m}\)) that coarsens aloft (\(\Delta z \sim 100\text{--}500\text{ m}\)). Applying uniform finite-difference stencils to stretched grids introduces severe truncation errors and breaks discrete conservation laws.

5.1 Non-Uniform Vertical Grid Discretization

To enforce discrete conservation and accommodate variable grid spacing, the fourth-order hyperdiffusion operator is factorized into two sequential, cell-centered second-order diffusion steps on a staggered grid:

\mathcal{D}_4(Ri) = -\frac{\partial^2}{\partial z^2} \left[ \mathcal{K}_z(z) \frac{\partial^2 Ri}{\partial z^2} \right]

For a vertical grid with node heights \(z_k\) and dual-grid intervals \(\Delta z_k = z_{k+1} - z_k\):

1. Intermediate Cell-Centered Curvature (\(C_k\)): Compute intermediate physical profile curvature at cell centers (full levels) using non-uniform central differences: \(C_k = \frac{2}{\Delta z_k + \Delta z_{k-1}} \left[ \frac{Ri_{k+1} - Ri_k}{\Delta z_k} - \frac{Ri_k - Ri_{k-1}}{\Delta z_{k-1}} \right]\)
2. Secondary Fourth-Order Update (\(\mathcal{D}_{4,k}\)): Apply the secondary curvature operator to \(C_k\): \(\mathcal{D}_{4,k} = \frac{2}{\Delta z_k + \Delta z_{k-1}} \left[ \frac{C_{k+1} - C_k}{\Delta z_k} - \frac{C_k - C_{k-1}}{\Delta z_{k-1}} \right]\)

On staggered C-grids, intermediate curvature \(C_k\) is evaluated at cell centers, whereas hyperdiffusivities \(\mathcal{K}_z(z)\) reside at cell interfaces. To ensure uniform attenuation of \(2\Delta z\) grid noise across all vertical levels without over-damping coarse cells aloft, local hyperdiffusivity scaling uses local cell thickness \(\Delta z_k\):

\(\nu_4(z_k) = \frac{(\Delta z_k)^4}{\tau_{\text{diff}}}\)

where \(\tau_{\text{diff}} = \alpha_d \Delta t\) (with \(\alpha_d \in [2.0, 5.0]\)) represents the target grid-scale e-folding damping timescale.

5.2 Boundary Condition Engineering

Fourth-order differential operators require two boundary conditions at each domain interface:

 Upper Boundary (\(z = z_{\text{top}}\))  ──►  \(C_N = 0\)  &  \((C_N - C_{N-1})/\Delta z_{N-1} = 0\)  (Zero-Curvature & Zero-Flux)
                                  │
                                  ▼
      Interior Domain        ──►  \(\mathcal{D}_{4,k} = -\frac{\partial^2}{\partial z^2} \left[ \mathcal{K}_z \frac{\partial^2 Ri}{\partial z^2} \right]\)  (Biharmonic Damping)
                                  ▲
                                  │
 Lower Boundary (\(z = z_0\))    ──►  \(C_1 = 0\)  &  \(\mathcal{D}_{4,1} = \mathcal{D}_{4,2} = 0\)  (Surface-Layer Clamping)

Lower Boundary (\(z = z_0\), Surface Layer)

Physics near the surface is governed by Monin–Obukhov Similarity Theory. Applying artificial numerical filters inside the lowest grid cells (\(k=1, 2\)) corrupts the diagnosed surface sensible heat flux \(H_s\) and friction velocity \(u_*\). Surface-layer clamping enforces \(C_1 = 0\) and \(\mathcal{D}_{4,1} = \mathcal{D}_{4,2} = 0\) for \(z \le z_1\).

Upper Boundary (\(z = z_{\text{top}}\), Free Atmosphere)

At the top model boundary, filters must prevent spurious reflection of high-wavenumber computational waves back down into the boundary layer. Enforce zero-curvature and zero-flux boundary conditions:

\(C_N = 0 \quad \text{and} \quad \frac{C_N - C_{N-1}}{\Delta z_{N-1}} = 0\)

5.3 Time Integration Strategies and Stability Bounds

Explicit time integration of fourth-order hyperdiffusion imposes a strict Courant–Friedrichs–Lewy (CFL) stability limit:

\[

\Delta t \le \sigma_{\max} \frac{(\Delta z_{\min})^4}{\nu_{4,\max}}
\]

where \(\sigma_{\max} \approx 0.0625\) for Forward Euler and \(\sigma_{\max} \approx 0.11\) for third-order Runge–Kutta (RK3). On fine vertical grids (\(\Delta z_{\min} < 10\text{ m}\)), this fourth-power scaling forces impractically small time steps.

To bypass explicit restrictions, three numerical integration solutions are utilized:

1. Explicit Sub-Stepping: Advancing hyperdiffusion over \(M\) sub-steps per global model time step: \(Ri_k^{n+1} = Ri_k^n - \sum_{m=1}^M \frac{\Delta t}{M} \nu_4(z_k) \mathcal{D}_{4,k}^m\).
2. Pentadiagonal Implicit Solver: Formulating updates implicitly via \((\mathbf{I} + \Delta t \mathbf{A}_4) \mathbf{Ri}^{n+1} = \mathbf{Ri}^n\), where \(\mathbf{A}_4\) is a pentadiagonal matrix solved in \(\mathcal{O}(N)\) operations using a 5-diagonal Thomas algorithm.
3. Biharmonic-Modified Forward Time-Stepping Method (Bertozzi, Ju, & Lu, 2009): For non-linear biharmonic equations \(\frac{\partial U}{\partial t} = -\nabla \cdot (f(U)\nabla \Delta U) + \nabla \cdot (g(U)\nabla U)\), adding and subtracting a linear biharmonic operator scaled by mobility prefactor \(M = \alpha \max(f(U^n))\) (with \(\alpha \ge 1.0\)) yields the unconditionally stable scheme:
\[
\frac{U^{n+1} - U^n}{\Delta t} + M \Delta^2 U^{n+1} = \nabla \cdot \left[\left(M - f(U^n)\right)\nabla \Delta U^n\right] + \nabla \cdot \left[g(U^n)\nabla U^n\right]
\]
Setting \(M = \alpha \max(f(U^n))\) with \(\alpha \ge 1.0\) isolates the implicit solve to a linear constant-coefficient biharmonic operator solved via Fast Fourier Transforms (FFTs) or pentadiagonal solves. This eliminates non-linear iterations, guarantees unconditional \(H^1\) norm stability, and satisfies discrete energy dissipation bounds \(F^n = \|\nabla U^n\|^2 + \Delta t M \|\nabla \Delta U^n\|^2 \le F^{n-1}\) with \(\mathcal{O}(\Delta t)\) convergence.

Having detailed spatial discretization and temporal integration schemes, the analysis concludes with a verification and auditing protocol.

1. Implementation, Verification, and Evaluation Protocol

To ensure numerical stability, scale selectivity, and physical conservation, vertical hyperdiffusion operators must undergo systematic auditing before deployment in operational NWP workflows.

6.1 Verification and Testing Workflow

Modelers should execute the following 7-step evaluation sequence:

1. Specify Target Wavelengths & Fields: Identify prognostic state variables requiring filtering \((u, v, \theta_v)\). Keep horizontal and vertical filtering operators decoupled, retaining physical turbulence closure formulations.
2. Isolated Operator Verification: Verify operator performance in single-column tests. Confirm constant-field preservation \(\mathcal{D}_4(1) = 0\), weighted mass conservation, monotonic quadratic norm decay \(\frac{dE_q}{dt} \le 0\), and theoretical Fourier decay rates \(\nu_{2p} k^{2p}\). Verify correct signs across fourth \(-\nu_4 \Delta^2 q\) and sixth \(+\nu_6 \Delta^3 q\) order operators.
3. Matched Damping Time Calibration: Compare fourth- and sixth-order operators using identical reference discrete modes \((2\Delta z)\) and matched damping times \(\tau_g\), rather than comparing raw numerical coefficients.
4. Physical Profile Verification: Test operators against analytical profiles, sharp nocturnal inversions, and Low-Level Jets using field benchmarks (such as GABLS3 or CASES-99). Inspect vector shear, TKE, physical turbulent fluxes, and diagnosed Ri alongside filter tendencies.
5. Vertical Resolution Convergence: Audit inversion layer thickness, LLJ speed, surface fluxes, and boundary-layer mixing depths under systematic vertical grid refinement \(\Delta z \to 0\).
6. Numerical Budget Auditing: Track filter-induced kinetic energy dissipation and scalar variance decay separately from physical turbulent transport tendencies. Record numerical dissipation as a separate budget sink.
7. Positivity & Boundary Auditing: Verify that filtering does not generate negative TKE or moisture, alter imposed surface momentum/heat fluxes, or excite spurious wave reflection at the upper domain boundary.

6.2 Practical Recommendations for Computational Dynamicists

* Default Operator Selection: Prioritize conservative, energy-dissipative fourth-order (biharmonic) filtering as the operational default. Biharmonic operators deliver superior scale selectivity over second-order Laplacian diffusion without the stencil width and boundary complexity of sixth-order operators.
* Selective Use of Sixth-Order Filters: Reserve triharmonic (sixth-order) filtering for configurations where fourth-order damping measurably erodes resolved inversion structures or jet noses at the damping rate required to suppress \(2\Delta z\) grid noise.
* Diagnostic Interpretation of Bell Expansion: Treat Bell-polynomial fold expansions strictly as diagnostic composition identities. They explain how derivative chains map across coordinate transforms, but do not represent physical turbulence generation or local profile stabilization.

Numerical filter design in atmospheric modeling must balance scale selectivity, discrete conservation, boundary preservation, and mathematical rigor.

High-Order Hyperdiffusion and Richardson Number Dynamics in Atmospheric Boundary-Layer Modeling: A Mathematical and Numerical Architecture Standard
1. Physical Closure Theory and Closed-Form Stability Inversions (\zeta \longleftrightarrow Ri \longleftrightarrow (S_m, S_h))
In Numerical Weather Prediction (NWP) models and Large-Eddy Simulation (LES) computational frameworks, the representation of sub-grid turbulent transport relies on non-dimensional Monin–Obukhov Similarity Theory (MOST) stability functions. Traditionally, determining the dimensionless stability parameter \zeta = z/L (where z is physical height [\text{m}] and L is the Obukhov length scale [\text{m}]) required sub-iterative convergence loops (such as L-convergence fixed-point iterations). In modern high-performance computing (HPC) environments—specifically highly vectorized SIMD architectures and GPU accelerators—such iterative loops create critical performance bottlenecks. Conditional branching across stability regimes and variable loop iteration counts induce severe thread and warp divergence, causing execution pipeline stalls and computational latency. Replacing legacy sub-iterative loops with exact, non-iterative, closed-form Gradient Richardson number (Ri) stability mappings removes these computational bottlenecks, enforces deterministic memory access patterns, prevents warp divergence, and guarantees exact algebraic self-consistency across unstable, neutral, and stable boundary-layer regimes.

1.1 Monin–Obukhov Similarity vs. Gradient Richardson Space: Mathematical Linkage and Exponent Consistency
First-order turbulent transport parameterizations model the turbulent exchange coefficients for momentum (K_m \, [\text{m}^2 \text{s}^{-1}]) and heat or scalars (K_h \, [\text{m}^2 \text{s}^{-1}]) using either the Monin–Obukhov similarity framework or local gradient Richardson number formulations. In similarity space, exchange coefficients are written as: K_m = \frac{l_m u_*}{\phi_m(\zeta)}, \qquad K_h = \frac{l_m u_*}{\phi_h(\zeta)} where l_m = \kappa(z - d) represents the surface-layer mixing length [\text{m}], \kappa \approx 0.40 is the von Kármán constant, d is the displacement height [\text{m}], u_* is the friction velocity [\text{m} \text{s}^{-1}], and \phi_m(\zeta), \phi_h(\zeta) are the dimensionless MOST gradient functions for momentum and heat, respectively. Alternatively, in local Gradient Richardson number space, exchange coefficients are defined as: K_m = S_m(Ri) \, l_m^2 s, \qquad K_h = S_h(Ri) \, l_m^2 s where s = |\partial \mathbf{V} / \partial z| is the total vertical vector shear magnitude [\text{s}^{-1}], and S_m(Ri), S_h(Ri) are dimensionless exchange stability functions that parameterize the damping or enhancement of turbulence due to thermal stratification.
To derive the exact mathematical bridge linking these two spaces, we equate friction velocity u_* = S_m^{1/2} l_m s and friction temperature \theta_* = (S_h / S_m^{1/2}) l_m (\partial \theta_v / \partial z) within the theoretical definition of the Obukhov length scale: L = \frac{u_*^2}{\kappa B \theta_*} where B = g / \theta_{v,\mathrm{ref}} is the buoyancy parameter [\text{m} \text{s}^{-2} \text{K}^{-1}]. Substituting u_* and \theta_* into L yields: L = \frac{S_m l_m^2 s^2}{\kappa B \left( \frac{S_h}{S_m^{1/2}} l_m \frac{\partial \theta_v}{\partial z} \right)} = \frac{l_m S_m^{3/2}}{\kappa B S_h \frac{\partial \theta_v / \partial z}{s^2}} Noting that the local Gradient Richardson number is Ri = \frac{B (\partial \theta_v / \partial z)}{s^2} and l_m = \kappa z (assuming zero displacement d=0), the expression for dimensionless height \zeta = z/L reduces to the fundamental dual transformation identity: \zeta(Ri) = Ri \frac{S_h(Ri)}{S_m^{3/2}(Ri)}
Evaluating this derivation demonstrates why the exponent 3/2 on S_m(Ri) in the denominator is a strict physical and mathematical requirement. Whenever the turbulent Prandtl number Pr_t = K_m / K_h = S_m(Ri) / S_h(Ri) = \phi_h(\zeta) / \phi_m(\zeta) deviates from unity (Pr_t \neq 1), any exponent other than 3/2 creates an algebraic mismatch between friction velocity definitions and local gradient scales, violating internal closure consistency and dimensional homogeneity.

1.2 Analytical Regime Inversions: Stable Quadratic Roots, Dyer Collapse, and Master Cubics
Under stable boundary layer conditions (\text{SBL}, Ri > 0), non-dimensional MOST gradient functions are modeled linearly as \phi_m(\zeta) = 1 + \beta_m \zeta and \phi_h(\zeta) = \alpha_\theta + \beta_h \zeta, where \alpha_\theta = Pr_t(0) is the neutral turbulent Prandtl number. Expressing the stability functions as S_m(Ri) = \phi_m^{-2}(\zeta) and S_h(Ri) = \phi_m^{-1}(\zeta)\phi_h^{-1}(\zeta) and substituting them into the transformation identity yields an explicit quadratic algebraic equation for \zeta(Ri): (\beta_m^2 Ri - \beta_h) \zeta^2 + (2 \beta_m Ri - \alpha_\theta) \zeta + Ri = 0 Solving this quadratic polynomial yields two analytical radical roots: \zeta_{\pm}(Ri) = \frac{\alpha_\theta - 2 Ri \beta_m \pm \sqrt{\alpha_\theta^2 + 4(\beta_h - \alpha_\theta \beta_m)Ri}}{2(Ri \beta_m^2 - \beta_h)}
Critiquing the root selection via rigorous limiting analysis demonstrates that selecting the negative radical root (-\sqrt{\cdot}) is physically and mathematically mandatory:

Direct Substitution at Neutrality (Ri = 0): Evaluating \zeta_-(Ri) directly at Ri = 0 gives: \zeta_-(0) = \frac{\alpha_\theta - 0 - \sqrt{\alpha_\theta^2 + 0}}{2(0 - \beta_h)} = \frac{\alpha_\theta - \alpha_\theta}{-2\beta_h} = \frac{0}{-2\beta_h} = 0 Direct substitution confirms that \zeta_-(0) = 0 exactly, enforcing the physical boundary condition that non-dimensional height vanishes at neutral stability. Conversely, selecting the positive root (+\sqrt{\cdot}) yields: \zeta_+(0) = \frac{\alpha_\theta + \alpha_\theta}{-2\beta_h} = -\frac{\alpha_\theta}{\beta_h} \neq 0 which introduces an unphysical step discontinuity at neutral stability and violates \zeta(0) = 0.
Initial Profile Slope Near Neutrality (\lim_{Ri \to 0^+} \frac{\mathrm{d}\zeta}{\mathrm{d}Ri}): Evaluating the initial slope requires determining the limit of the quotient \zeta_-(Ri)/Ri as Ri \to 0^+, which presents an indeterminate 0/0 form. Applying L'Hôpital's rule or expanding the square root via Taylor series \sqrt{\alpha_\theta^2 + 4(\beta_h - \alpha_\theta \beta_m)Ri} \approx \alpha_\theta + \frac{2(\beta_h - \alpha_\theta \beta_m)}{\alpha_\theta} Ri + \mathcal{O}(Ri^2) yields: \lim_{Ri \to 0^+} \frac{\zeta_-(Ri)}{Ri} = \lim_{Ri \to 0^+} \frac{\alpha_\theta - 2 Ri \beta_m - \left[\alpha_\theta + \frac{2(\beta_h - \alpha_\theta \beta_m)}{\alpha_\theta} Ri\right]}{2 Ri (Ri \beta_m^2 - \beta_h)} = \frac{-2 \frac{\beta_h}{\alpha_\theta}}{-2 \beta_h} = \frac{1}{\alpha_\theta} Thus, the negative root enforces both \zeta(0) = 0 and the smooth initial linear slope \left.\frac{\mathrm{d}\zeta}{\mathrm{d}Ri}\right|_{Ri=0^+} = \frac{1}{\alpha_\theta}.
In the equal-diffusivity limit (\alpha_\theta = 1, \beta_m = \beta_h = \beta), the asymptotic critical Richardson number threshold is Ri_c = 1/\beta. Under these conditions, the exchange stability functions reduce to a piecewise quadratic formulation: S_m(Ri) = S_h(Ri) = \begin{cases} \left(1 - \frac{Ri}{Ri_c}\right)^2, & 0 \le Ri < Ri_c \\ 0, & Ri \ge Ri_c \end{cases} Evaluating derivatives as Ri \to Ri_c^- yields S(Ri_c^-) = 0 and S'(Ri_c^-) = 0. Consequently, the quadratic formulation possesses C^1 derivative continuity across the extinction threshold Ri_c, suppressing derivative jumps and preventing numerical delta-function spikes in spatial gradients. However, while C^1 continuity eliminates spatial gradient jumps, S(Ri) is not C^2 continuous because S''(Ri_c^-) = 2/Ri_c^2 \neq 0 = S''(Ri_c^+). Furthermore, vanishing exchange diffusivities (K_m, K_h \to 0) in Very Stable Boundary Layer (\mathrm{VSBL}) regimes can cause land-surface models to decouple, triggering runaway nocturnal surface cooling. Modern \mathrm{VSBL} formulations (e.g., Gryanik et al., 2020) address this operational failure by replacing hard zero-extinction thresholds (Ri_c) with non-zero asymptotic tails (\phi_m, \phi_h \sim \zeta^1 as \zeta \to \infty), maintaining physical transport coupling under extreme stability.
Under unstable boundary layer conditions (\mathrm{UBL}, Ri < 0), standard empirical formulations adopt Businger–Dyer exponents (\alpha_m = -1/4, \alpha_h = -1/2), mapping non-dimensional profiles into a master cubic equation in variable x \equiv \zeta: b_m \zeta^3 - \zeta^2 - b_h \left(\frac{Ri}{\alpha_\theta}\right)^2 \zeta + \left(\frac{Ri}{\alpha_\theta}\right)^2 = 0 When momentum and scalar empirical exponents match identically (b_m = b_h = B_u \approx 16, \alpha_\theta = 1.0), the stability functions evaluate to S_m(Ri) = (1 - B_u \zeta)^{1/2} and S_h(Ri) = (1 - B_u \zeta)^{3/4} = S_m^{3/2}(Ri). Substituting these functions into the dual transformation identity produces: \zeta = Ri \frac{S_h(Ri)}{S_m^{3/2}(Ri)} = Ri \frac{(1 - B_u \zeta)^{3/4}}{(1 - B_u \zeta)^{3/4}} \equiv Ri This identity represents the "Dyer Collapse" (\zeta \equiv Ri identically across Ri \le 0). The radical powers cancel perfectly, eliminating the master cubic equation entirely and allowing direct, exact, non-iterative evaluation of unstable stability profiles.

1.3 GPU-Native Execution Architectures: Zero-Offset Hyperbolic Regularization (Z0HR) and Lagrange Inversion Kernels
High-performance GPU and SIMD acceleration requires removing conditional execution branching (if/else logic across Ri = 0) to eliminate warp divergence, instruction pipeline flushing, and thread execution stalls. To achieve branch-free execution, Zero-Offset Hyperbolic Regularization (Z0HR) decomposes Ri into C^\infty-differentiable positive (stable) and negative (unstable) projections using an \epsilon-regularized absolute value: |Ri|_\epsilon = \sqrt{Ri^2 + \epsilon^2} Ri_+ = \frac{1}{2}\left(Ri + |Ri|_\epsilon - \epsilon\right), \qquad Ri_- = \frac{1}{2}\left(Ri - |Ri|_\epsilon + \epsilon\right) Regime blending is controlled via continuous hyperbolic tangent weights: w_{\text{stable}} = \frac{1}{2}\left(1 + \frac{Ri}{|Ri|_\epsilon}\right) which smoothly transition from 0 (unstable) to 1 (stable) over a narrow regularized band [-\epsilon, +\epsilon].
Near neutral stability (|Ri| \ll 1), directly evaluating rational stability mappings can introduce floating-point precision loss and catastrophic cancellation. To eliminate numerical instability near Ri \approx 0, a two-layer Julia/SIMD-native computational kernel is deployed. Layer 1 pre-computes physical coefficients and universal Lagrange series reversion coefficients, while Layer 2 evaluates a Horner-form polynomial kernel. Strict type parameterization T is enforced across all literal constants to prevent implicit type promotion from Float32 to Float64 during single-precision GPU pipeline execution:

module MOSTInversionArchitectures

export compute_lagrange_coeffs, solve_zeta_z0hr

"""
Layer 1: Physics Pre-computation Kernel.
Derives forward Taylor expansion coefficients c_k for Ri(ζ) and computes
universal Lagrange inversion coefficients a_k for ζ(Ri) near neutral stability.
"""
@inline function compute_lagrange_coeffs(Pr_t0::T, β_m::T, β_h::T) where {T<:AbstractFloat}
    # Forward Taylor coefficients: Ri(ζ) = c1*ζ + c2*ζ² + c3*ζ³ + O(ζ⁴)
    c1 = Pr_t0
    c2 = β_h - T(2.0) * β_m * Pr_t0
    c3 = T(3.0) * β_m * β_m * Pr_t0 - T(2.0) * β_m * β_h

    # Universal Lagrange Series Reversion: ζ(Ri) = a1*Ri + a2*Ri² + a3*Ri³ + O(Ri⁴)
    c1_inv = T(1.0) / c1
    a1 = c1_inv
    a2 = -c2 * (c1_inv * c1_inv * c1_inv)
    a3 = (T(2.0) * c2 * c2 - c1 * c3) * (c1_inv * c1_inv * c1_inv * c1_inv * c1_inv)

    return (a1, a2, a3)
end

"""
Layer 2: SIMD/GPU-Native Branch-Free Z0HR Solver.
Evaluates ζ(Ri) continuously across all regimes without conditional branching.
Strict type parameterization T prevents single-to-double precision promotion.
"""
@inline function solve_zeta_z0hr(
    Ri::T,
    a_coeffs::NTuple{3, T};
    Ri_c::T=T(0.19),
    Pr_t0::T=T(1.0),
    ϵ::T=T(1e-6)
) where {T<:AbstractFloat}
    # 1. Zero-Offset Hyperbolic Regularization (Z0HR) Split
    abs_ri_ϵ = sqrt(Ri * Ri + ϵ * ϵ)
    Ri_pos   = T(0.5) * (Ri + abs_ri_ϵ - ϵ)
    w_stable = T(0.5) * (T(1.0) + Ri / abs_ri_ϵ)

    # 2. Near-Neutral / Unstable Lagrange Kernel (Horner Form)
    a1, a2, a3 = a_coeffs
    zeta_neutral = Ri * (a1 + Ri * (a2 + Ri * a3))

    # 3. Stable Branch via Smooth Quadratic Closure
    denom_stable = max(T(1.0) - Ri_pos / Ri_c, ϵ)
    zeta_stable  = (Ri_pos / Pr_t0) / denom_stable

    # 4. C^∞ Smooth Regime Blending (Branch-Free Execution)
    return (T(1.0) - w_stable) * zeta_neutral + w_stable * zeta_stable
end

end # module MOSTInversionArchitectures
These exact non-iterative physical closures provide the necessary foundation for mapping profile dynamics into spatial height coordinates via high-order differential composition rules.

2. Faà di Bruno Composition Geometry and Partial Bell Matrix Systems (\mathbf{R}_\zeta \xrightarrow{\mathbf{B}} \mathbf{R}_z)
Evaluating spatial gradients of stability functions (Ri_z, Ri_{zz}, Ri_{zzz}, Ri_{zzzz}) is essential for higher-order spatial discretizations, adaptive vertical turbulent diffusion schemes, and biharmonic hyperdiffusion operators. When non-dimensional similarity representations R(\zeta) are mapped into physical vertical coordinates z, higher-order chain differentiation generates complex combinatorial couplings between intrinsic stability curvature and geometric coordinate stretching. Faà di Bruno’s higher-order chain rule organizes these combinatorial derivative chains into structured lower-triangular matrix systems, enabling exact spatial transformations without truncation error.

2.1 Higher-Order Spatial Derivatives and the Lower-Triangular Bell Matrix Structure
Let Ri(z) = R(\zeta(z)) represent a smooth composite profile function, where \zeta(z) = z / L(z) maps physical height z \, [\text{m}] into similarity space. The m-th physical vertical derivative \frac{\mathrm{d}^m Ri}{\mathrm{d}z^m} \, [\text{m}^{-m}] is governed by Faà di Bruno’s chain rule: \frac{\mathrm{d}^m}{\mathrm{d}z^m} R(\zeta(z)) = \sum_{n=1}^{m} R^{(n)}(\zeta) \cdot B_{m,n}(g_1, g_2, \dots, g_{m-n+1}) where R^{(n)}(\zeta) = \frac{\mathrm{d}^n R}{\mathrm{d}\zeta^n}, g_j \equiv \frac{\mathrm{d}^j \zeta}{\mathrm{d}z^j} \, [\text{m}^{-j}] represents spatial coordinate derivatives, and B_{m,n}(g_1, g_2, \dots, g_{m-n+1}) are partial exponential Bell polynomials (Bell polynomials of the second kind). Algebraically, B_{m,n} counts the set partitions of m items into n non-empty subsets.
Collecting derivative components up to fourth order yields the explicit 4 \times 4 lower-triangular Partial Bell Transformation Matrix system \mathbf{Ri}_z = \mathbf{B} \mathbf{R}_\zeta: \begin{bmatrix} Ri_z \\ Ri_{zz} \\ Ri_{zzz} \\ Ri_{zzzz} \end{bmatrix} = \begin{bmatrix} g_1 & 0 & 0 & 0 \\ g_2 & g_1^2 & 0 & 0 \\ g_3 & 3g_1g_2 & g_1^3 & 0 \\ g_4 & 4g_1g_3 + 3g_2^2 & 6g_1^2g_2 & g_1^4 \end{bmatrix} \begin{bmatrix} R'(\zeta) \\ R''(\zeta) \\ R'''(\zeta) \\ R^{(4)}(\zeta) \end{bmatrix}
The polynomial entries B_{m,n} within matrix \mathbf{B} can be constructed using two equivalent recurrence relations:

Combinatorial Summation Recurrence (Faà di Bruno Identity): B_{m+1, n} = \sum_{j=n-1}^{m} \binom{m}{j} g_{m+1-j} B_{j, n-1} \quad \text{with } B_{0,0} = 1
Subroutine-Friendly Differential Recurrence: B_{m+1, n} = g_1 B_{m, n-1} + \frac{\mathrm{d}}{\mathrm{d}z} B_{m, n} with boundary conditions B_{m,0} = 0 for m \ge 1 and B_{m,k} = 0 for k > m.
2.2 Matrix Inversion (\mathbf{B}^{-1}) and Near-Neutral Curvature Spikes vs. Asymptotic Decay
Because matrix \mathbf{B} is lower-triangular, its determinant is the product of its diagonal elements: \det(\mathbf{B}) = g_1 \cdot g_1^2 \cdot g_1^3 \cdot g_1^4 = g_1^{10} Provided g_1 = \zeta_z \neq 0, matrix \mathbf{B} is non-singular and strictly invertible. Inverting the system yields the exact inverse mapping \mathbf{R}_\zeta = \mathbf{B}^{-1} \mathbf{Ri}_z: \begin{bmatrix} R'(\zeta) \\ R''(\zeta) \\ R'''(\zeta) \\ R^{(4)}(\zeta) \end{bmatrix} = \begin{bmatrix} \frac{1}{g_1} & 0 & 0 & 0 \\ -\frac{g_2}{g_1^3} & \frac{1}{g_1^2} & 0 & 0 \\ \frac{3g_2^2 - g_1 g_3}{g_1^5} & -\frac{3g_2}{g_1^4} & \frac{1}{g_1^3} & 0 \\ \frac{10g_1 g_2 g_3 - 15g_2^3 - g_1^2 g_4}{g_1^7} & \frac{10g_2^2 - 4g_1 g_3}{g_1^6} & -\frac{6g_2}{g_1^5} & \frac{1}{g_1^4} \end{bmatrix} \begin{bmatrix} Ri_z \\ Ri_{zz} \\ Ri_{zzz} \\ Ri_{zzzz} \end{bmatrix}
In observational parameter calibration frameworks, \mathbf{B}^{-1} enables researchers to diagnose local non-dimensional similarity derivatives (R', R'', R''', R^{(4)}) directly from physical field tower or LES spatial profiles without assuming a priori functional forms for the closures.
Evaluating non-dimensional profile curvature near neutral stability (\zeta \to 0) demonstrates a critical structural divergence between single-coefficient and dual-coefficient MOST formulations:

Single-Coefficient Closure (R(\zeta) = \frac{\zeta}{1 + \beta \zeta} with \beta = 5.0): R''(0) = -2\beta = -10.0
Dual-Coefficient Closure (R(\zeta) = \frac{\zeta(\alpha_\theta + \beta_h \zeta)}{(1 + \beta_m \zeta)^2} with \alpha_\theta = 1.0, \beta_m = 6.0, \beta_h = 5.0): R''(0) = 2(\beta_h - 2\alpha_\theta \beta_m) = 2(5.0 - 12.0) = -14.0
The dual-coefficient formulation generates a ~40% steeper initial curvature spike near neutrality (R''(0) = -14.0 vs. -10.0). On discrete vertical grids, unattenuated prefactor terms near \zeta \to 0 cause this steeper curvature spike to accelerate spatial gradient growth near the surface: \lim_{\zeta \to 0} Ri_{zzzz} = g_4 + R''(0) (4g_1 g_3 + 3g_2^2) + R'''(0) (6g_1^2 g_2) + R^{(4)}(0) g_1^4 This spatial derivative growth provides explicit mathematical justification for mandatory softening noise floor parameters (\epsilon_c Ri_c > 0) in surface-layer routines to bound numerical derivative growth near the surface without corrupting physical turbulent fluxes.
In the high-stability limit (\zeta \gg 1), higher-order non-dimensional derivatives decay as power laws: R^{(n)}(\zeta) \approx (-1)^n n! \, \frac{\alpha_\theta \beta_m - 2\beta_h}{\beta_m^3} \zeta^{-(n+1)} \sim \mathcal{O}\left(\zeta^{-(n+1)}\right) Assuming a constant local Obukhov length scale L, the physical coordinate derivative evaluates to g_1 = 1/L, yielding \frac{\mathrm{d}^n Ri}{\mathrm{d}z^n} \propto \frac{L}{z^{n+1}}. For fourth-order physical derivatives, this scales aloft as: Ri_{zzzz} \propto z^{-5} This rapid z^{-5} power-law decay proves that MOST closures naturally damp sub-grid numerical noise aloft. Consequently, persistent grid-scale oscillations observed aloft in stable atmospheric layers during model integration indicate non-MOST physical processes (e.g., gravity wave breaking or shear instability) or numerical boundary reflections, rather than inherent MOST model instability.

2.3 Kinematic Profiling: Decoupling the Low-Level Jet "Nose" from the Coordinate Fold "Knee"
Atmospheric boundary-layer profiling requires decoupling two physically and mathematically distinct phenomena:

The Low-Level Jet (LLJ) "Nose": A physical fluid-dynamical momentum maximum at height z_{\text{LLJ}} where total vertical vector shear magnitude vanishes (s = |\partial \mathbf{V}/\partial z| \to 0 \, [\text{s}^{-1}]). Because shear appears squared in the denominator of Ri = N^2/s^2, point-gradient Ri values diverge toward +\infty. Note that a scalar wind speed maximum alone does not imply s=0 if directional wind shear is present.
The Coordinate "Knee" (Coordinate Fold Singularity): A 1D mathematical projection artifact where vertical flux divergence balances similarity scaling (\zeta L' = 1), causing the coordinate transformation derivative to vanish (g_1 = \zeta_z = 0 \, [\text{m}^{-1}]) and destroying local coordinate invertibility (\det(\mathbf{B}) = g_1^{10} = 0).
At a coordinate fold (g_1 = 0, g_2 \neq 0), matrix \mathbf{B} collapses into a sparse, rank-deficient structure: \mathbf{B}\Big|_{g_1=0} = \begin{bmatrix} 0 & 0 & 0 & 0 \\ g_2 & 0 & 0 & 0 \\ g_3 & 0 & 0 & 0 \\ g_4 & 3g_2^2 & 0 & 0 \end{bmatrix} \implies \begin{bmatrix} Ri_z \\ Ri_{zz} \\ Ri_{zzz} \\ Ri_{zzzz} \end{bmatrix}_{g_1=0} = \begin{bmatrix} 0 \\ R'(\zeta) g_2 \\ R'(\zeta) g_3 \\ R'(\zeta) g_4 + 3 R''(\zeta) g_2^2 \end{bmatrix}
At g_1 = 0, the physical gradient vanishes (Ri_z = 0). The intrinsic stability curvature R''(\zeta) is multiplied by g_1^2 = 0 and drops out of the second derivative, leaving physical profile bending governed entirely by coordinate geometry (Ri_{zz} = R'(\zeta) g_2). At fourth order, the non-zero entry B_{4,2} = 3g_2^2 retains the active similarity term 3 R''(\zeta) g_2^2.

3. Mechanics of Scale-Selective Hyperdiffusion Operators (q \xrightarrow{\mathcal{D}_{2p}} q^*)
High-order spatial hyperdiffusion operators provide scale-selective numerical dissipation in atmospheric models. Their primary function is to attenuate high-wavenumber computational grid noise near the spatial truncation limit (2\Delta z) while preserving resolved physical fluid structures, such as nocturnal inversions and shallow shear layers.

3.1 Dissipative Sign Conventions, Fourier Eigenvalue Calibration, and Discrete Over-Damping Factors

3.2 Global Norm Conservation vs. Local Non-Monotonicity and Maximum Principle Violations
For a variable-coefficient biharmonic operator formulated in self-adjoint form: \mathcal{D}_4(q) = -\frac{\partial^2}{\partial z^2}\left[\mathcal{K}_z(z) \frac{\partial^2 q}{\partial z^2}\right] where \mathcal{K}_z(z) \ge 0 \, [\text{m}^4 \text{s}^{-1}], integrating over domain \Omega with zero-flux boundary conditions proves global quadratic norm dissipation (E_q = \frac{1}{2} \langle q, q \rangle): \left.\frac{\mathrm{d}E_q}{\mathrm{d}t}\right|_{\mathrm{filter}} = \int_\Omega q \left( -\frac{\partial^2}{\partial z^2}\left[\mathcal{K}_z(z) \frac{\partial^2 q}{\partial z^2}\right] \right) \mathrm{d}z = -\int_\Omega \mathcal{K}_z(z) \left( \frac{\partial^2 q}{\partial z^2} \right)^2 \mathrm{d}z \le 0
While global norm decay guarantees variance dissipation, fourth- and higher-order hyperdiffusion operators lack a pointwise maximum principle. Unlike second-order diffusion, high-order operators can generate localized unphysical overshoots and undershoots (Gibbs ringing) near sharp inversions or scalar fronts. Non-linear flux limiters (such as TVD or Zalesak multidimensional limiters) must be enforced when filtering positive-definite prognostic scalar fields (q_v, q_c, e).
Furthermore, strict operational separation must be maintained between prognostic time integration and diagnostic profile analysis: \text{Prognostic State } (u, v, \theta_v, q_v) \xrightarrow{\text{Prognostic Filter } \mathcal{D}_{2p}} (u^*, v^*, \theta_v^*, q_v^*) \xrightarrow{\text{Diagnostic Evaluation}} Ri^* Prognostic state variables receive hyperdiffusive filtering during model updates. Richardson number hyperdiffusion filters (\mathcal{D}_4(Ri)) are strictly analytical diagnostics and must never be applied directly as momentum or thermal state updates.

3.3 Staggered Grid Factorization, Physical Boundary Closures, and Stencil-Dependent CFL Stability Bounds
On non-uniform vertical grids with cell spacing \Delta z_k = z_{k+1} - z_k, fourth-order hyperdiffusion is factorized into two sequential cell-centered second-order diffusion steps:

Intermediate Cell-Centered Curvature (C_k): C_k = \frac{2}{\Delta z_k + \Delta z_{k-1}} \left[ \frac{q_{k+1} - q_k}{\Delta z_k} - \frac{q_k - q_{k-1}}{\Delta z_{k-1}} \right]
Secondary Biharmonic Update (\mathcal{D}_{4,k}): \mathcal{D}_{4,k} = \frac{2}{\Delta z_k + \Delta z_{k-1}} \left[ \frac{\mathcal{K}_{z,k+1/2} \frac{C_{k+1} - C_k}{\Delta z_k} - \mathcal{K}_{z,k-1/2} \frac{C_k - C_{k-1}}{\Delta z_{k-1}}}{1} \right]
Boundary conditions are implemented as follows:

Lower Boundary (Surface Layer, z \le z_1): Apply Surface-Layer Clamping (C_1 = 0, \mathcal{D}_{4,1} = \mathcal{D}_{4,2} = 0). Clamping prevents artificial numerical filtering within the surface layer, preserving physical surface momentum (u_*) and heat (H_s) fluxes diagnosed via MOST.
Upper Boundary (Domain Top, z = z_{\text{top}}): Enforce Zero-Curvature (C_N = 0) and Zero-Hyperdiffusive-Flux (\frac{C_N - C_{N-1}}{\Delta z_{N-1}} = 0) conditions to prevent wave reflection at domain tops.
Explicit time stepping enforces a strict Courant-Friedrichs-Lewy (CFL) stability bound: \Delta t \le \sigma_{\max} \frac{(\Delta z_{\min})^4}{\nu_{4,\max}} where \sigma_{\max} = 0.125 for Forward Euler integration (\sigma_{\max} \approx 0.11 for RK3). On fine vertical meshes (\Delta z < 5\text{ m}), explicit restrictions become prohibitive. Numerical stability is maintained using an implicit pentadiagonal solver: \left[ \mathbf{I} + \Delta t \mathbf{A}_4 \right] \mathbf{q}^{n+1} = \mathbf{q}^* where \mathbf{A}_4 is the factorized biharmonic matrix operator. This pentadiagonal system is solved efficiently in \mathcal{O}(N) computational time via a 5-diagonal Thomas algorithm.
From a GPU hardware acceleration perspective, solving independent vertical tridiagonal or pentadiagonal systems per horizontal grid column maps efficiently to GPU thread blocks. However, memory bandwidth limitations and thread warp execution bounds require careful memory stride alignment. Contiguous memory layouts (e.g., column-first [z, x, y] ordering vs. horizontal slice [x, y, z] ordering) must be maintained to maximize coalesced global memory access and minimize SIMD lane synchronization stalls during the implicit forward-backward substitution passes.
Discrete numerical filters must be integrated with observational diagnostic frameworks to evaluate profile curvature on real-world vertical grids.

4. Generalized Similarity Profile Theory (GSPT) and Observational Profile Analysis
Generalized Similarity Profile Theory (GSPT) provides a diagnostic framework to analyze field tower profiles (e.g., CASES-99, GABLS3) and high-resolution LES outputs. GSPT isolates intrinsic physical profile curvature from coordinate transformation geometry and finite-difference estimation error.
